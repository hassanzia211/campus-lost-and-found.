# Campus Lost & Found

A simple Flutter application for browsing lost and found items on a university campus.

## Features

- Displays eight campus lost-and-found items using `ListView.builder`.
- Shows each item's name, location, and status.
- Provides a button to open the selected item's details.
- Uses Flutter navigation with `Navigator.push` and `Navigator.pop`.

## Run the project

1. Install Flutter and configure an Android emulator or connect an Android device.
2. Clone this repository.
3. Open the project folder in a terminal.
4. Run:

```bash
flutter pub get
flutter run
```
